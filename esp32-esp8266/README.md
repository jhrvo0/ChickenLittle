# Firmware ESP32

O firmware e a configuração PlatformIO estão em [firmware/](../firmware/); a entrada principal é [firmware/main/main.cpp](../firmware/main/main.cpp). O projeto utiliza ESP32, sem módulo ESP8266 na montagem atual.

Este diretório é um ponto de entrada acadêmico, sem cópia do código. Consulte a [arquitetura](../docs/motionlab_arquitetura.md) e a [Fase E](../docs/motionlab_fase_e.md) para a parte IoT. A aceitação dessa organização deve ser confirmada com os professores.
