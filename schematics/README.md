# Esquemas e montagem

A montagem vigente, sem LCD, está descrita nas [ligações de bancada](../docs/bench_verified_wiring.md), na [netlist atual](../hardware/netlist/motionpet_atual_sem_lcd.json) e no [diagrama Wokwi](../hardware/wokwi/montagem_atual/diagram.json). No Wokwi não existe peça TCRT5000: o sensor infravermelho é representado por um módulo de sensor de luz (`tcrt_marcador`), com os mesmos pinos VCC, GND e DO. Outros desenhos e geradores estão em [hardware/](../hardware/); alguns representam versões históricas com LCD.

Este diretório é um ponto de entrada acadêmico, sem duplicação dos diagramas. A aceitação dessa organização deve ser confirmada com os professores.
