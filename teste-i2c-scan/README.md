# teste-i2c-scan

Scanner I²C (PlatformIO, ESP32), usado para achar o endereço do LCD (0x27).

**Legado do LCD, fora da montagem desde 2026-11-10.** O LCD 2004 I²C ficou ilegível em 3,3 V e, em 5 V, exigiria um conversor de nível que não está disponível. A interface web no notebook (`python -m terminal.web`) o substitui. Este projeto é mantido só como recurso; não faz parte da montagem atual (ver `docs/bench_verified_wiring.md`).
